# 📖 《系统分析与设计》期末必考通关手册

欢迎使用本手册！本通关手册完全基于《系统分析与设计》期末必考重点，结合 **Alan Dennis 经典教材体系** 与 **软考高级标准** 进行了全面拓展和深挖。

每一部分都包含了**理论提炼、绘图规范、代码/表结构模版以及手把手例题解析**，旨在帮助您在考场上拿到高分甚至满分。

---

## 🎯 目录与快速导航

根据期末大题考核规格（分析大题1道30分、简答大题1道20分、设计大题5道50分，无选择题及计算题），本手册删除了所有不考的财务计算，整合为以下三个核心模块，点击下方链接即可进入对应章节：

### 1. [第一部分：四大必考 UML 绘图标准与高分范式](./01-uml-standards/)
*   **类图与设计类图 (DCD)**：三层架构设计、主外键 `{PK}/{FK}` 标注规范。
*   **用例图 (Use Case Diagram)**：系统边界、包含与扩展关系的规范箭头指向。
*   **活动图 (Activity Diagram)**：Fork/Join 并行控制流、决策点与守卫条件。
*   **设计级对象序列图 (Sequence Diagram)**：生命线命名规范、生命周期与条件判定。

### 2. [第二部分：核心理论、操作契约与用例实现实战](./02-core-theories/)
*   **第一分部**：项目可行性与操作契约。
*   **第二分部**：设计原则、GRASP、SOLID、架构风格与经典设计模式。
*   **第三分部**：从 Kotlin 业务代码到操作契约、SSD、设计级顺序图与 DCD 的完整实践。

### 3. [期末模拟试卷：A/B 套试题与参考答案](./03-mock-exams/)
*   **第一部分**：A 套分析题、简答题、设计大题及参考答案。
*   **第二部分**：B 套分析题、简答题、设计大题及参考答案。
*   每道题的评分标准、Mermaid 图示、代码骨架和表结构设计均保留在对应小节中。

---

> [!TIP]
> **备考建议**：
> - **绘图与设计题**：期末大题画图占比高达 80%（分析大题 30 分 + 设计大题 50 分）。考前务必在草稿纸上对照第一部分手绘练习 A、B 两套模拟卷中的绘图大题，特别注意**空心三角**与**虚线箭头**的规范性。
> - **简答题**：背诵第二部分及模拟卷简答大题中关于“内聚与耦合级别”、“操作契约后置条件”以及“SOLID原则”的经典定义与说明。
